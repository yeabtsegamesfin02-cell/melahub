# Melahub

Melahub is a student opportunity platform for Ethiopian students, connecting them to scholarships, internships, training programs, and fellowships.

## Project structure

- `frontend/` - React + Vite frontend
- `backend/` - Node.js + Express backend

## Frontend

- Install packages:
  `cd frontend && npm install`
- Run app:
  `npm run dev`

## Backend

- Install packages:
  `cd backend && npm install`
- Run app:
  `npm run dev`

## Main pages

- Home
- Opportunities
- Opportunity details
- Login
- Register
- Profile
- Dashboard
